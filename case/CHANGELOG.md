# 演进记录

每个版本对应书里的一章。读者可以 `git checkout` 到任意一章看当时的代码。

| 版本 | 那一章 | 改了什么 | 为什么 |
|---|---|---|---|
| `v0.1` | 00 | 起点：1 个文件 44 行 | 能用。这是全书要回到的参照点 |
| `v0.2` | 00 | 让 AI「重构得专业点」→ 7 个文件 149 行，4 个抽象 | 每个文件单看都合理，结构上多余。**同时丢了 HTML 转义** |
| `v0.3` | 05 | 加渲染层：接口 + 两个类；另附一份纯函数版 | 一个只有单方法的接口就是一个函数类型 |
| `v0.4` | 06 | 语法从 2 种涨到 6 种；`branches.ts` 对照 `rules.ts` | 分支变数据。两版输出逐字节一致，验证脚本在文件注释里 |
| `v1.1` | 16 | 终点：6 个文件，内联掉三个直通层 | `NoteStore` 改由使用方定义（异步 `all`/`append`），消费者从 1 个变成 3 个 |

```bash
# 跑 npm run verify:v0.4（需要先在 case/ 下 npm install）
# 8 个样例 × 6 组开关，输出全部逐字节相同
```

## v1.1 相对 v0.2 的变化

删掉：`NoteFactory`、`NoteRepository`、`NoteService`（三个直通层）。

保留并改形：存储抽象。v0.2 那个接口照抄 localStorage（同步 `load`/`save`），v1.1 改由使用方定义（异步 `all`/`append`），并加了第二个真实实现 `MemoryNoteStore`。

新增：渲染规则数组、标签解析、唯一的渲染入口。
