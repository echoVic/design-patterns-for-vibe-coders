# v0.1 —— 能用

一个 HTML 文件、一个 TS 文件，共 55 行。打开就能写，停手 400ms 自动存进 localStorage。

**这是全书的起点，也是终点。** 第 00 章从这里开始，第 16 章回到这里做对比。

## 怎么跑

```bash
cd case && npm install && npm run dev
# 打开 http://127.0.0.1:5180/v0.1/
```

**需要构建步骤。** 浏览器不执行 TypeScript——`<script src="./main.ts">` 会静默失败：样式加载了，但应用完全不跑。

（我一开始在 README 里写了「浏览器原生支持 TS 剥离类型，直接打开就行」，那是错的。实测过才知道：页面上什么都没有，控制台也没有明显报错，很容易被当成「还没来得及写逻辑」。）
