# v0.4 —— 六种语法，两种写法

第 06 章的对照版本。同一个功能，两份实现：

```
src/render/branches.ts   六个 if 堆在一起（直觉写法）
src/render/rules.ts      六条规则一个数组（整理之后）
src/render/index.ts      应用实际用的是这一份
```

**两份的输出逐字节一致。** 这一点很重要——第 06 章论证的是「结构不同、行为相同」，如果输出有差异，论证就不成立。

验证方法：`cd case && npm run verify:v0.4`。它跑 8 个样例 × 6 组开关，逐字节比对。

## 相对 v0.3 的变化

v0.3 里那套类版渲染器（`renderer.ts` + 两个实现类）已经删掉了。第 05 章已经论证过「一个只有单方法的接口就是一个函数类型」，那一版不该留到这一章。

`branches.ts` 保留在仓库里，只作为对照，**应用没有 import 它**。
